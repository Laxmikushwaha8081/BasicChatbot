# BasicChatbot

A simple rule-based chatbot built with Python.

## Features
- Greets the user with a welcome message
- Responds to basic greetings like "hello"
- Answers "how are you"
- Says goodbye when the user enters "bye"
- Handles unknown input gracefully

## Run the project

Open a terminal in the project folder and run:

```bash
python chatbot.py
```

## Example conversation

```text
You: hello
Chatbot: Hi!

You: how are you
Chatbot: I'm fine, thanks!

You: bye
Chatbot: Goodbye!
```

## Files
- `chatbot.py` — main chatbot logic
